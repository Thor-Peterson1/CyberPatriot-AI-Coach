# 🛡️ CyberPatriot OPS Mentor
An interactive, full-stack web application designed to help student competitors practice system hardening, security auditing, and forensic hunting outside of official competition rounds.

## Live Demo
🔗 [[Click here to use the app live on Streamlit!]((https://cyberpatriot-ai-coach-hwgjzy84chosdl8ykadbxc.streamlit.app/#cyberpatriot-ops-mentor))]

## Key Features
* **Dynamic Training Scenarios:** Simulates misconfigured Windows/Linux server states to test competitor logic.
* **Concept-First Guidance:** Uses specialized pedagogical prompt design to teach underlying security mechanics rather than giving away direct scripts.
* **Interactive Study Tools:** Automated short quiz generator, instant answer-reveal shortcuts, and early-season point target checklists.
* **Live Analytics Monitor:** Built-in resource tracking counters to measure data throughput and simulate enterprise token cost-management.
* **Session Manager & Data Export:** Supports persistent multi-session history logs and complete text-transcript file compilation downloads.

## Tech Stack
* **Language:** Python 3
* **UI Framework:** Streamlit 
* **AI Engine:** Groq Developer Cloud API (`openai/gpt-oss-20b`)
* **Infrastructure Deployment:** Streamlit Community Cloud

## Compliance Notice
*This tool is intended strictly for off-season and out-of-round training. In accordance with official CyberPatriot regulations, automated AI tools, scripts, or assistance are completely prohibited during active competition matches.*
